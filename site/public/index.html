Connect Wavr to your space and it starts understanding what is there.

Wavr fuses network scanning, Bluetooth, camera and radar signals into one explainable presence state per room: occupied or not, a confidence score, and the per-modality why behind it. It runs entirely on hardware you already own, whether that's a laptop, a mini PC, or a Raspberry Pi. Nothing leaves the box unless you turn on an optional, clearly-labelled egress.

Install Wavr View source on GitHub

There is no hosted demo. Wavr is local-only by design; read the source, or run it yourself against simulated data with python -m wavr.serve, which needs no hardware at all.

Local-first, on purpose

Home sensing usually means sending your camera feed and network traffic to someone else's cloud. Wavr takes the opposite position: the same sensing techniques, run on a machine you control, with the data staying on it.

Loopback by default

The base install never opens a LAN socket. Every path off the box (LAN multi-device, MQTT to Home Assistant, the MCP control tool, the AI narrator) is opt-in and starts OFF.

Cameras boot off

Frames live in RAM only, are never written to disk, and never leave the box. Only derived state (occupancy, confidence, a timestamp) is ever stored or shared.

No account, no telemetry

No sign-up, no analytics SDK, no phone-home. The dashboard makes zero external requests, and this website doesn't either. See Privacy.

AGPL-3.0-or-later

Free and open source for personal, self-hosted and non-commercial use. Run a modified version as a network service and the AGPL asks you to publish your changes. A commercial license is available from the author on request.

Explainable by construction

Fused confidence equals the best present evidence: trust weight × the source's own confidence × freshness decay, so a single weak source never fakes certainty. Every source's own reading is surfaced, never silently arbitrated.

A room is always shown in one of three honest states: confirmed-empty, offline (a sensor stopped reporting), or no coverage. They're never blended into a false "clear."

One brain, every screen

Wavr is a small family of surfaces around one local fusion engine. Add the ones you need, over the same authenticated, local-only channel.

Desktop

The full dashboard as a native shell, or straight from source in a browser. The machine that runs it is the "Core".

MCP for agents

A read-only Model Context Protocol server exposes room state and the house map so your own agents can query presence, with an opt-in, gated Home Assistant control tool.

Mobile companion

No app-store app needed. Pair a phone or tablet browser to a Core over local HTTPS and add it to your home screen.

Sensor Nodes

A small radar or PIR board that joins Wavr over Wi-Fi with a one-time code. See Nodes for what's built and what's still firmware-only.

Ready when you are

Zero hardware to try the idea, and a real path to an always-on household hub when you want one.
