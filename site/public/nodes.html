Nodes

A Node is a small, headless sensor board (an ESP32 with a radar or motion sensor) that joins Wavr over Wi-Fi and reports into fusion for one room. It's how you cover a room without running a cable to a camera or plugging a sensor straight into your Core.

What it takes

Shopping list
  • An ESP32 dev board (~€5–8)
  • An HLK-LD2450 24 GHz radar module (~€10–15)
  • 4 jumper wires and a USB cable
Toolchain

PlatformIO (CLI or the VS Code extension). Everything else is pulled automatically on first build.

Time

Roughly 15–20 minutes end to end once your toolchain is set up, including Wi-Fi provisioning and enrollment.

How a Node joins, in plain terms

  1. You name it first. In Wavr, you pick a name, a room, and a sensor type before the Node exists to the system. The Node itself never chooses these: a compromised board can't relocate itself or relabel what it claims to be.
  2. Wavr shows a one-time code (five-minute expiry, rate-limited).
  3. You type that code into the Node's own setup page, which it opens as a temporary Wi-Fi hotspot the first time it boots.
  4. The Node joins your Wi-Fi and redeems the code. Its room lights up in fusion within seconds of its first reading.

The Node also pins Wavr's certificate the first time it connects, so a later man-in-the-middle can't quietly intercept its credentials. The one moment that trust is established is worth watching: compare the fingerprint the Node prints on its setup page against your Core's own, before you walk away.

The kill switch is physical on purpose

Wavr can turn a Node off remotely. It can never turn one back on remotely.

Disabling a Node from the dashboard (or the API) stops it from feeding fusion immediately. Re-enabling it requires someone physically at the device: a short press on its button. That asymmetry isn't a missing feature, it's the design: there is no admin or remote "turn back on" route anywhere in the code for a Node to be re-armed without a person standing next to it.

Ready to try it?

In Wavr's Settings (the gear icon), turn on "Let other devices connect" and then "Accept sensor nodes". Both ask you to confirm, because together they are what lets something other than this machine talk to Wavr. Then go to Nodes → Add a node. Everything else, including flashing the board itself, is in the full guide.
